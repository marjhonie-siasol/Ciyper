API Keys Setup & Security
  • Primary Key: The main key used for transcriptions, audio analysis, and copilot answers.
  • Backup Keys: Two backup keys that automatically rotate in if your Primary Key hits rate limits or fails.
  • Local Storage: Credentials are stored privately on your local machine and never sent to external servers.
  • Direct connection: Connects directly to Groq's official endpoint, ensuring transcript privacy.
API Usage & Metrics
  • Sparkline Graphs: Real-time request volume trends over the last 7 days. Hover to view daily query counts.
  • Free Tier Limits: Groq has a rate limit depending on your developer plan (e.g. 14,400 RPD).
  • Key Status Badges: Displays whether each key is active, rate-limited, or unused.
My Files & Context Info
  • Resume: A text file (.txt format) detailing your background and experience. Useful for interview matching.
  • Context: Support files detailing your coding style, specific project architectures, and codebase rules.
  • AI Rules: Direct guidelines governing how the AI behaves and formats its code responses.
  • Local Security: All resumes and context files are stored securely inside your local JSON database.
Recent Sessions Info
  • Sessions List: Shows history of saved meeting or interview sessions, including date and duration.
  • Delete Sessions: Click the delete trash icon next to a session to permanently remove it from your database.
  • Titling: Sessions are titled automatically based on the conversation topic or context summary.
