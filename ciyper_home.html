Model Selection Guide

Powered by Groq's latest production and developer models. view models

  • openai/gpt-oss-120b: Flagship open-weight 120B reasoning model (MoE) for complex software engineering interviews, advanced algorithms, and deep math logic. Features a 131k context window and a 65k max output limit.
    Pros: Frontier-grade reasoning, exceptional coding accuracy, and long-horizon problem solving (~500 tps).
    Cons: Larger token compute footprint compared to 20B.
  • openai/gpt-oss-20b: Ultra-fast, lightweight 20B Mixture-of-Experts (MoE) model optimized for real-time interview transcripts, conversational banter, and immediate answers. Offers a 131k context window and a 65k max output limit.
    Pros: Blazing speed (~1,000 tokens/sec), sub-second latency, highly cost-effective and responsive.
    Cons: Slightly less specialized on theoretical multi-tier architectural edge-cases than 120B.
  • qwen/qwen3.8-27b: Compact 27B dense model tailored for agentic coding, multi-step environment planning, and technical STEM problem solving with a 131k context window and 16k output limit.
    Pros: Strong code synthesis, detailed technical explanations, flexible reasoning modes.
    Cons: 16k max completion token ceiling.
Documentation & User Guide

Welcome to Ciyper documentation. Below is a detailed description of all features and tab operations.

API Analytics
  • Usage Tracking: Tracks and plots request volume trends and query counts processed over the last 7 days.
  • Key Status Monitoring: Displays and monitors the real-time health status of each key (Healthy, Rate Limited, Invalid, or No key) to track active rotation failover.
  • Active Failover Indicator: Visually reflects backup key activation on your status cards in real time if the active session triggers the proactive failover rotation.
Recent Sessions
  • Session History Tracking: Displays your history of past sessions, indicating the date, duration, and AI-generated summary of each recorded session.
  • Permanent Removal: Click the red trash icon next to a session to delete its log permanently from your local registry database.
My Files & Resume Context
  • TXT Format Requirement: The system strictly accepts `.txt` file formats because the AI can easily parse raw text file contents.
  • Resume Information Reader: Uploading your resume allows the AI to fully read your professional details and structure answers to represent you.
  • Additional Context Upload: Upload support context files detailing further work experiences or personal characteristics so the AI knows who you are and represents you accurately.
API Keys Management
  • Groq API Execution: Connects directly to Groq Cloud services using your active API credentials to power transcription and chat replies.
  • Local Storage Security: All API Keys are saved directly to your local application database file. Your keys are never uploaded to any remote server or cloud.
  • Optional Backup Keys: Configuring Backup Key 1 and/or 2 is optional. For optimal reliability, backup keys should belong to different Groq accounts to bypass restrictions on multiple keys under one account.
  • Proactive Failover Rotation: The app predicts connection issues (like HTTP 429 rate limit blockages) before generating replies, displaying warnings, and rotating credentials dynamically to prevent session disruption.
AI Models Integration
  • Pre-Session Options: Choose which AI model you want to proceed with before starting a chat session, offering complete options control.
  • Groq Production Catalog: The catalog and backend API executions are based directly on Groq's official production model listings and documentation.
  • Model Capabilities & Power: Gives you direct control over processing power, ranging from ultra-fast ~1000 tps conversational models (like openai/gpt-oss-20b) to flagship reasoning engines (like openai/gpt-oss-120b) for complex logic tasks.
Local Data & Security
  • 100% Local Filesystem: Because this project is fully open source, you have absolute control over your keys. Your API credentials, file uploads, and session details are stored locally inside database.json. Your data is never shared with developers or third-party servers.
  • Access Data Directory: Copy and run any of these commands in your terminal to print the database JSON contents directly:
    PowerShell command
    Get-Content "$env:APPDATA\ciyper\database.json"
    Command Prompt (CMD) command
    type "%APPDATA%\ciyper\database.json"
    macOS/Linux Terminal command
    cat ~/Library/Application\ Support/ciyper/database.json
